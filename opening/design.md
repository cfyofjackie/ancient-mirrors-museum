# 为铜镜博物馆增加 4 秒开场动画

请先阅读并理解当前项目代码，确认页面结构、技术栈、铜镜组件、现有交互以及素材目录，再开始修改。

这次任务只增加一个简短的开场动画，不要重构主展厅，不要改变现有的铜镜切换、滑动、翻面等功能。

为“中国古代铜镜互动展 / 铜镜小博物馆”增加一个约 4 秒的开场序厅。

4. 自然进入现有“照见千年”页面。

它不是完整宣传片，也不是多页文化介绍，而是一次短暂、克制的视觉过渡。总时长控制在 3.8～4.3 秒，不能超过 5 秒。

## 三、整体视觉要求

开场必须延续现有页面的视觉语言：

* 深青黑、墨黑偏灰的背景；
* 轻微纸张颗粒和古籍质感；
* 极低对比度的细线几何暗纹；
* 暖米白文字；
* 少量朱红只能作为极弱点缀；
* 古画边缘自然消失在黑暗中；
* 留白充足；
* 安静、克制、现代数字展览感。

不要做成：

* 传统古风海报；
* PPT式图片轮播；
* 大面积金色边框；
* 满屏书法；
* 仙气、烟雾、粒子爆炸；
* 强烈聚光灯或游戏开场；
* 写实的3D博物馆房间。

## 四、动画时间线

### 0～0.25秒：背景建立

显示与主页面一致的深青黑背景、纸张颗粒和淡淡的几何暗纹。

不要纯黑闪屏，也不要加载动画。

### 0.25～1.20秒：《磨镜图》浮现

从《磨镜图》中裁切出以下主体：

* 右下方正在磨镜的工匠；
* 工匠的双手；
* 桌面；
* 正在被打磨的圆形铜镜。

主体放在画面下半部分，建议偏右。其他围观人物可以非常暗地保留在左侧，像尚未完全浮现的历史影像。

古画不要保留明显的矩形边界，通过渐变遮罩让边缘融入背景。

这一阶段先不要出现完整长文案。

### 0.70～1.35秒：第一行文字出现

在屏幕上方约 24%～28% 的中央位置显示：

“以铜为镜”

文字要求：

* 暖米白色；
* 现代宋体或项目现有的中文衬线字体；
* 不使用毛笔书法字体；
* 字距适当拉开；
* 字重偏轻；
* 不要描边、发光和明显阴影；
* 使用透明度渐显，并伴随约 6～10px 的轻微上移；
* 不要逐字打字。

### 1.20～2.55秒：过渡到《对镜仕女图》

《磨镜图》逐渐退暗，《对镜仕女图》从下半部分柔和浮现。

重点保留：

* 对镜的仕女；
* 身后的侍女；
* 左下方的大镜台；
* 侍女手中的小镜子。

不要硬切，不要左右分屏。两幅画需要有短暂重叠，表现历史场景之间的自然叠化。

《磨镜图》中的工匠可以在右下方短暂保留为低透明度残影，然后完全淡出。

### 1.55～2.30秒：第二行文字出现

在“以铜为镜”下方显示：

“可以正衣冠”

排版要求：

* 第一行字号较大；
* 第二行字号约为第一行的 55%～65%；
* 第二行透明度比第一行低；
* 两行居中；
* 行距舒展；
* 整个文字块不要超过屏幕宽度的 50%；
* 不能遮挡人物或镜子。

### 2.55～3.45秒：画中镜转为展品

这是整个开场最重要的过渡。

执行以下变化：

1. 两行文字逐渐淡出；
2. 仕女和侍女逐渐退入背景；
3. 左下方的大镜台或画中的圆形镜面成为视觉锚点；
4. 镜面缓慢放大并向主页面铜镜的最终位置移动；
5. 在移动过程中，由古画中的镜面叠化为项目当前使用的真实铜镜素材或铜镜组件。

不要直接把画中镜瞬间替换成主铜镜，也不要突然切换页面。

如果直接对镜台做复杂形变不稳定，可以使用匹配剪辑：

* 先放大画中镜；
* 在两面镜子的圆形轮廓接近时进行交叉淡化；
* 主铜镜接管缩放和位移动画；
* 最终准确落到主页面原本的位置。

最后阶段必须使用项目原本的铜镜素材或组件，不能用生成参考图中的铜镜替代。

### 3.45～4.05秒：进入主展厅

古画完全退场，开场遮罩逐渐消失，露出原本的主页面。

主页面现有文字随页面自然出现：

“照见千年”

“从一面铜镜，看见不同时代的审美”

主标题和副标题可以使用约 0.4～0.6 秒的淡入，但不要再次播放复杂动画。

铜镜落位以后，立即恢复主页面原本的滑动、切换、翻面等交互。

## 五、图层建议

建议将开场做成覆盖在主页面上的 fixed overlay，主页面提前在下方完成渲染，避免动画结束时重新加载或跳动。

开场可以拆为：

1. 背景与暗纹层；
2. 《磨镜图》图层；
3. 《对镜仕女图》图层；
4. 文案图层；
5. 用于衔接的铜镜图层；
6. 已经渲染在下方的主页面。

古画图层使用：

* `opacity`
* `transform`
* `filter`
* CSS `mask-image` 或渐变遮罩

让画面边缘融入深色背景。

动画优先使用 `opacity` 和 `transform`，减少昂贵的实时滤镜，保证小红书内置浏览器和普通手机上的流畅度。

如果项目已经安装动画库，可以沿用现有方案；如果没有，不要为了这个短动画引入体积很大的依赖，优先使用 CSS Animation、Web Animations API，或项目已有的轻量动画方式。

## 六、文字样式

开场文字沿用现有页面的字体气质和颜色体系。

推荐参数可根据实际页面适配：

* 主句颜色：`rgba(235, 226, 205, 0.9)`
* 次句颜色：`rgba(210, 202, 185, 0.62)`
* 标题字距：约 `0.22em～0.32em`
* 次标题字距：约 `0.16em～0.24em`
* 文字区域：屏幕顶部安全区下方，约 `24vh～28vh`
* 文本对齐：居中

文字必须使用真实 HTML 文本，不要把生成图片里的文字直接烘焙成图片，以保证不同屏幕尺寸下清晰且可控。

## 七、交互与播放规则

* 开场只在用户首次进入展厅时播放；
* 当前会话内从详情页返回主展厅时不要重复播放；
* 可以使用 `sessionStorage` 记录本次会话是否已经播放；
* 用户点击或轻触开场区域时，可以直接快速结束动画并进入主页面；
* 不需要放醒目的“跳过”按钮；
* 跳过时也要正确清理定时器、动画状态和遮罩；
* 开场结束后 overlay 必须移除或设为不可交互，不能阻挡主页面触摸操作；
* 支持 `prefers-reduced-motion`：如果用户开启减少动态效果，则使用约 0.3～0.5 秒的简单淡入，或直接进入主页面。

## 八、移动端适配

重点适配竖屏手机。

要求：

* 不同屏幕比例下，人物和镜子不能被关键区域裁掉；
* 文字避开顶部浏览器栏和系统安全区；
* 使用 `100dvh` 或兼容方案，避免移动浏览器地址栏导致高度跳动；
* 动画过程中页面不能滚动；
* 动画结束后恢复原有滚动行为；
* 图片提前预加载，避免开场中途闪白；
* 主页面不能因为开场动画发生布局位移。

## 九、不要修改的内容

* 当前铜镜列表；
* 朝代切换逻辑；
* 铜镜翻面交互；
* 页面正文；

* 主页面整体排版；
* 已经存在的背景暗纹风格；
* 现有路由结构。
