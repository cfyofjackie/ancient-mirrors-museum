# 5. 文物工作台版

为中国古代铜镜互动小工具设计一张“文物整理工作台”风格的竖版背景。

不是考古现场，也不是凌乱实验室，而是非常整洁、高级的文物研究桌面。

背景可以是浅灰褐、淡木色或低饱和米灰色桌面。

画面边缘出现少量与文物研究相关的视觉元素：
- 极淡标尺
- 小型标签卡
- 半透明薄纸
- 记录纸
- 手套的一角
- 极细辅助线
- 编号标记感

中央留出完全干净区域用于展示铜镜。

整体感觉：
“这件铜镜刚刚被放到研究台上，准备被观察。”

风格要高级、极简、克制，不要科技实验室感，不要工业风，不要出现真实文字，不要生成铜镜。

关键词：
artifact conservation table, museum research desk, archival workspace, minimal curatorial aesthetic, soft neutral palette, elegant cultural object display, subtle documentation elements, clean composition.
