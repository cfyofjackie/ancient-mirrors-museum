## 发现清单（按影响排序）

### P1-① 墙面金色装饰线读作"渲染毛边"——"不对劲"的最大来源（已解决）

- **现象**：画面上散布着看似随机的细金线、悬空矩形框、网点块、一段圆弧。放大后第一观感是"这页没渲染完"，而非设计。
- **证据**：`ui-audit.local/shots/c1-header-before-flip.png`（顶部展签放大图：左上角一截突然断掉的横线、屏幕左缘悬空矩形框）；`06-hall-tang-front.png` / `07-hall-han-front.png`（两侧竖线被屏幕裁切）。
- **根因**：`src/textures/wall-base.svg` 的"金色细线装饰"组——`x=72/828` 两条竖线（其中一条中途断开）、`y=102` 横线、三个矩形框（x≈60-160）、两块 halftone 网点、右缘一段大圆弧。这些装饰按 900×1600 viewBox 定位，而背景 `cover`/`slice` 缩放随视口变化，**装饰与实际内容（镜子、展签）永不对齐**，起止位置又无构图逻辑。
- **建议**：直接删除该装饰组（保留底色渐变、光池、铜绿、暗角、颗粒层）。负空间本身即是博物馆感；若日后要恢复"板缝"暗示，须改为与镜面对齐的 DOM 覆盖元素（随内容定位），不要放回背景 SVG。
- **成本/风险**：改一个 SVG，零逻辑风险。

### P1-② 镜面正面是"素盘"，观感如贴图未加载（已解决；部分根因已更正）

- **现象**：背面纹饰翻过来后，正面是一块均匀米金色扁平圆盘，是全片最弱的一帧；且恰好发生在"照见千年"点题时刻（照人）。
- **根因（更正）**：当时正面材质为 `MeshStandardMaterial({ color: FRONT_COLOR, metalness: 0.72, roughness: 0.5, envMapIntensity: 0.28 })`，没有 `map` 或 `roughnessMap`，因此读作均匀素盘；场景当时已经使用 `RoomEnvironment` 生成环境反射，“无环境贴图”不是事实，反射偏强反而放大了光滑和过亮感。
- **建议**：先做程序化"抛光古铜面"纹理（运行时 canvas 生成：径向温变光泽 + 边缘薄暗斑/包浆 + 极淡同心打磨纹），作为 `map` 绑到正面材质，并下调 metalness/roughness 匹配。零素材、零网络、静态纹理（不触碰按需渲染红线）。后续照镜人像（第二批）确定素材后在此基础上叠加。
- **成本/风险**：只动正面材质一处；`material.needsUpdate` 遵守"仅纹理槽位首次赋值"约定。

### P2-③ 资料卡馆藏白底图是"刺眼白方块"；标题折行难看（已解决）

- **现象**：暗色宣纸卡片中央，博物馆白底方图直接呈现，现有径向渐隐（`mask-image`，`opacity: 0.92`）压不住白底；破坏"精致感"仅次于 ①。另外热点卡/资料卡标题折行出现"（妇好墓出 / 土）"式断法。
- **证据**：`ui-audit.local/shots/b4-ref-sheet.png`。
- **根因**：`src/index.css` `.ref-figure img` 的融合手段（径向 mask）只对"图内背景与卡片色相近"有效，对纯白底方图无效——白底与深色卡的对比是硬边。标题无 `text-wrap: balance`。
- **建议**：思路反转——**把白色变成有意的装裱**：给图外加米白卡纸边框（padding + 纸色底）、细内阴影、轻纸纹（可复用 `wall-grain.svg`），读作博物馆图签卡片；图宽度略收（如 88%）。标题加 `text-wrap: balance`。
- **成本/风险**：纯 CSS。

### P2-④ 史实资料按钮改印章质感（已解决：方章、无涟漪）

- **方向**（用户 2026-09-08 口述确认）：胶囊改**方章**（圆角 4px 级）、**印泥斑驳底**（多层 radial-gradient 叠浓淡）、字距收紧、**删除外扩涟漪动画**、删除现有"册"形 `::before` 图标、加一圈极细米白内描边模拟刻边。
- **保留**：44px 级热区、hover 提亮、active 微缩、`prefers-reduced-motion` 降级、`pointer-events: auto`（容器穿透逻辑不变）。
- **涉及**：`src/index.css` `.ref-entry` 及 `.app-footer.text-enter .ref-entry` 双动画共存规则（去涟漪后该共存 hack 一并简化）、`@keyframes ref-entry-pulse` 删除。
- **成本/风险**：纯 CSS；注意 text-enter 入场动画与剩余动画列表的对应关系要同步清理。

### P3 小项（本轮已处理布局、尺寸与控件降噪；仍以真机验收为准）

1. **镜子稍放大**：`.mirror-3d-wrap` / `.mirror-face` 的 `min(76cqw, 76cqh, 560px)` → 约 80cqh 档，缓解上下空旷；以不侵入顶部展签/底部按钮为准，逐视口截图验证。
2. **提示行淡出**：`.hint`（"上下滑动切换朝代 · 点击铜镜翻面"）首次成功翻页后淡出（App 已有翻页状态可挂），常驻提示是 UI 噪音。
3. **磨镜图上缘渐隐**：序厅第一页画作顶边是生硬直线切边（`01-opening-p1.png`），加一段 mask 渐隐融入墙面。
