## 下一批功能路线图（四层，按建议实施顺序）

### 第一批：氛围层（解决"像照片"）——建议下一步先做

1. **光池呼吸**：展墙光池缓慢明暗起伏（CSS animation，零渲染成本）；
2. **浮尘微粒**：光池中极稀疏金色微尘缓慢漂浮（CSS 粒子层，克制、低透明度）；
3. （可选）镜面高光流动：three.js 高光随时间缓移——需恢复交互期间渲染，与按需渲染兼容，排后。

### 第二批：照镜人像（叙事核心，"照见千年"的点题）

- **正面（镜面）浮现模糊的该朝代古人面孔**，似有似无；转回背面消失；
- 素材方向**待用户确认**：公有领域古画裁切（仕女图/历代帝王像）或 AI 生成古风面孔；每朝一张；
- 与"拭镜交互"联动（见第三批）：擦亮镜子才照见人。

### 第三批：调色 + 做旧（材质层）

- **材质预设 A/B/C**：亮金（现状）/ 哑光古铜 / 黑漆古，POC 页挂开关对比（`?mode=` 已有 toon 通道，扩展预设参数即可）；
- 每朝可独立（汉黑漆古、唐亮金）；
- **做旧质感**（锈斑/包浆层）与本批同系统合并做。

### 第四批：交互 + 字体 + 音效

1. **陀螺仪**：倾斜跟随；iOS `requestPermission` 挂开场结束的首次触摸（钩子已在 OpeningOverlay 预埋 TODO）；特性检测+降级（小红书 webview 可能不支持）；
2. **拭镜交互**：手指在镜面往返擦拭 → 高光渐亮 → 触发照镜人像（与第二批联动）；
3. **印章质感按钮**：史实资料胶囊保留形态+涟漪，质感融合印泥（圆角改方章感 4px、印泥纹理底）——不动热区与涟漪；
4. **书法风格字体**（用户计划后续换）：层级方案=标题/朝代名用书法体、正文保持文楷；换字体重跑 `npm run font:subset`；注意竖排题跋渲染与生僻字覆盖、**选免费商用授权**（候选：演示悠然小楷、汇文明朝体等）；
5. **音效**（可选最后）：翻面金属轻响+氛围底噪（本地打包，自动播放策略注意）。

## 技术红线（持续有效，详见 HANDOFF.md）

1. 零网络约束（小红书沙箱）：不引入 CDN/外链/新依赖/在线字体；
2. 渲染器常驻+按需渲染：**不恢复空闲持续渲染**；不恢复"每次切换重建渲染器"；
3. `material.needsUpdate` 只在纹理槽位 null→纹理 首次赋值时设置；
4. `dragY` 单写入者：动画与拖拽手势不得同时写（pointerdown 先 stop）；
5. base './' 相对路径；deploy 流程与 git 流程不变；
6. 测试陷阱：内置预览/后台页 rAF 与 React 提交冻结，动态行为必须前台真机验证；
7. mirrors.ts 批量修改后跑完整性校验脚本（id 唯一/每镜 img+ref+art3d+hotspots，见 8b64a96 事故教训）。
