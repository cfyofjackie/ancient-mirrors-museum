# 翻页与渲染修复记录

本地分支：`codex/fix-mirror-transitions`。基于 `fcfa009`，保留 3D、页面布局、四朝数据和相对资源路径。原始问题见同目录诊断报告。

## 已实施

**统一翻页状态。** 拖拽、退场、等待新镜、入场共用一个控制器。旧页先滑动并淡出，opacity=0 时才替换朝代与位置；新镜的贴图、几何和首帧准备完才显现。删除镜子内部的独立升起动画。慢资源等待超过 350ms 显示加载提示。

**恢复有效输入。** 按钮恢复点击命中。滑动按距离 ≥70px，或距离 ≥20px 且最近速度 ≥350px/s 判定，横向移动不会误作点击。支持中断进出动画、快速反向、最近一次方向排队；非主指针、pointercancel、失焦都不误提交。资料卡中的滚动/键盘不影响背景页。

**按需绘制。** renderer 常驻，镜体轮廓几何缓存。只有素材变化、翻面、鼠标倾斜、尺寸变化及恢复可见时绘制；动作完成后停止 rAF。触摸拖拽仅移动外层页面。DPR 上限仍为 2，各向异性采样上限为 4。

**纹理与生命周期。** 每个 renderer 持有自己的 Promise 缓存，加载中请求可合并；当前镜优先，之后逐面准备其他镜子，上传串行分批让出主线程。map 与 normalMap 同时绑定；首次 shader 准备后再显示。超时/加载失败/WebGL 丢失可回退 CSS，回退路径也保留翻面、热点和就绪通知。清理覆盖纹理、几何、环境贴图、材质、监听器和定时器，并避免 StrictMode 清理误伤同一个 canvas 的新场景。

## 回归范围

自动化脚本回放真实挂载页面的事件处理链路，并检查 DOM 命中、朝代、动画恢复和渲染姿态：

- ↑↓ 按钮命中、正反向快速短滑。
- 手势取消恢复、非主指针、横向移动不误翻面。
- 退场途中反向、进入途中再次拖动、退场中被新拖动接管。
- 翻面反转、翻面中换朝代后重置到纹样背面。
- 资料卡屏蔽背景翻页、关闭后恢复；热点重新出现并能打开卡片。
- 无 WebGL 回退；注入贴图失败后的回退；注入 800ms 素材延迟时正常等待和恢复。

测试工具只在本地诊断服务器注入，普通 `npm run build` 不包含探针与故障注入代码。原始 JSON 在 `scripts/diagnostics/results/`，用法见该目录上级 README。
