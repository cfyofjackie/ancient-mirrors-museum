# 美术素材生成 Prompt 手册（M4.5 · 风格化拟物版）

> 用途：给生图模型（即梦 / Midjourney / DALL·E 等）直接粘贴，或整份扔给 Codex / ChatGPT 讨论迭代。
> 交接规格（尺寸 / 体积 / 命名 / 交付方式）见 [PROGRESS.md](../PROGRESS.md) 第八节。
>
> **风格定位：风格化拟物（stylized skeuomorphic）**——有体积、有材质、有重量感的"器物"，但用厚涂插画的笔触语言表达，不做照片级写实。
> 为什么不写实：写实的上限是博物馆实拍图（史实资料卡里已有），主视觉的职责是审美与氛围，且风格化才能保证 8 张图成套。
>
> **底线：拟物 ≠ 卡通。** 体积感、金属质感、厚度必须在——点击翻面的体验依赖"这是一件有重量的器物"的感觉。避免纯扁平、描边贴纸感、Q 版卡通。

---

## 一、全局统一要求（每一条 prompt 都要带上）

1. **画布**：正方形，≥ 1024×1024（Midjourney 建议 2048 upscaled）；
2. **构图**：镜子为正圆形，**完整居中、不裁切、不倾斜**，镜体外径约占画布宽度 86%，四周留均匀空边；
3. **视角**：**正视**（镜头垂直对准镜面），不要 3/4 侧角、不要透视变形；
4. **光照**：统一**左上方主光、右下弱补光**，加一圈**极轻的轮廓光（rim light）**让镜子从深色背景中浮起；背景无投影或仅极轻接触阴影；
5. **背景**：**纯深灰色无缝背景（#1a1a1a），无纹理、无渐变光斑、无桌面、无道具**——方便后期按圆形抠图转透明；
6. **质感语言**：游戏道具图标插画 / 厚涂（thick paint），立体拟物；细节风格化简化但材质要"可信"——金属的高光、锈斑的层次、浮雕的起伏都要在；
7. **负面要求**（生图模型通用负面词）：
   > 照片写实、摄影质感、真人实拍、文字、水印、签名、边框、画框、人手、现代物品、卡通、二次元、Q 版、扁平贴纸、描边线稿、塑料感、过度鲜艳、背景花纹、桌面
8. **一致性技巧**（很重要）：先出**汉·镜背**，满意后将它作为风格参考图（Midjourney 用 `--sref 图片URL`；即梦用"垫图/参考图"功能）生成其余 7 张，保证成套；
9. **Midjourney 英文风格后缀**（需要时可拼接在 prompt 末尾）：
   > stylized skeuomorphic game item icon art, thick painterly rendering, bronze material with real volume and weight, clean circular silhouette, subtle rim light, dark seamless background --no photo, realistic, flat, cartoon

### 汉 · 四神博局纹镜（铜色基调：黑漆古，深黑褐）

**Back（先出这张，定风格）**

## 三、朝代背景纹理 · 4 条 Prompt（可选 B 轨）

> 用途：全屏背景，替代当前纯渐变。**必须暗色低对比**（页面主体是镜子，背景抢戏即失败）。比例 9:16（1080×1920 即可）。插画质感，非照片。

**通用负面词**：亮色、高对比、具象大花纹、人物、建筑、文字、水印、照片写实

**汉**

> 极暗色插画纹理背景，纵向手机壁纸比例：深黑与暗漆红交融的丝绢质感，隐约可见极淡的汉代云气纹暗纹若隐若现，低调沉稳，低对比，博物馆展柜氛围，无主体，无亮部。

**唐**

> 极暗色插画纹理背景，纵向手机壁纸比例：深褐与暗金棕交织的织物质感，隐约可见极淡的唐代团花暗纹，华贵而克制，低对比，无主体，无亮部。

**宋**

> 极暗色插画纹理背景，纵向手机壁纸比例：青灰色水墨绢本质感，隐约可见极淡的远山淡影，极简素雅，低对比，无主体，无亮部。

**明**

> 极暗色插画纹理背景，纵向手机壁纸比例：朱褐与暗金交织的织锦质感，隐约可见极淡的缠枝暗纹，端庄沉稳，低对比，无主体，无亮部。
