# 美术素材生成 Prompt 手册（M4.5）

> 用途：给生图模型（即梦 / Midjourney / DALL·E 等）直接粘贴，或整份扔给 Codex / ChatGPT 讨论迭代。
> 交接规格（尺寸 / 体积 / 命名 / 交付方式）见 [PROGRESS.md](../PROGRESS.md) 第八节。
> 核心原则：**八张镜子图必须像"一套"**——统一视角、统一光照、统一构图；朝代差异靠**纹样与铜色基调**表达。

---

## 一、全局统一要求（每一条 prompt 都要带上）

1. **画布**：正方形，≥ 1024×1024（Midjourney 建议 2048 upscaled）；
2. **构图**：镜子为正圆形，**完整居中、不裁切、不倾斜**，镜体外径约占画布宽度 86%，四周留均匀空边；
3. **视角**：**正视**（镜头垂直对准镜面），不要 3/4 侧角、不要透视变形；
4. **光照**：统一**左上方主光、右下弱补光**，镜体下缘可有轻微反射光；背景无投影或仅极轻接触阴影；
5. **背景**：**纯深灰色无缝背景（#1a1a1a），无纹理、无渐变光斑、无桌面、无道具**——方便后期按圆形抠图转透明；
6. **负面要求**（生图模型通用负面词）：
   > 文字、水印、签名、边框、画框、人手、现代物品、塑料感、过度鲜艳、高饱和、卡通、二次元、朦胧雾效、背景花纹、桌面、投影过重
7. **质感基线**：实体感青铜（brass/bronze），有金属光泽与厚度，**不要平涂插画感**；风格词用「博物馆文物摄影，棚拍灯光，超写实细节」；
8. **一致性技巧**（很重要）：先出**汉·镜背**，满意后将它作为风格参考图（Midjourney 用 `--sref 图片URL`；即梦用"垫图/参考图"功能）生成其余 7 张，保证成套。

## 三、朝代背景纹理 · 4 条 Prompt（可选 B 轨）

> 用途：全屏背景，替代当前纯渐变。**必须暗色低对比**（页面主体是镜子，背景抢戏即失败）。比例 9:16（1080×1920 即可）。

**通用负面词**：亮色、高对比、具象大花纹、人物、建筑、文字、水印

**汉**

> 极暗色纹理背景，纵向手机壁纸比例：深黑与暗漆红交融的丝绢质感，隐约可见极淡的汉代云气纹暗纹若隐若现，低调沉稳，低对比，博物馆展柜氛围，无主体，无亮部。

**唐**

> 极暗色纹理背景，纵向手机壁纸比例：深褐与暗金棕交织的织物质感，隐约可见极淡的唐代团花暗纹，华贵而克制，低对比，无主体，无亮部。

**宋**

> 极暗色纹理背景，纵向手机壁纸比例：青灰色水墨绢本质感，隐约可见极淡的远山淡影，极简素雅，低对比，无主体，无亮部。

**明**

> 极暗色纹理背景，纵向手机壁纸比例：朱褐与暗金交织的织锦质感，隐约可见极淡的缠枝暗纹，端庄沉稳，低对比，无主体，无亮部。

## 四、交付清单

| # | 文件 | 落位 |
|---|---|---|
| 1–8 | 四朝 × 正/背面镜（PNG 原图） | `assets-src/mirrors/<han|tang|song|ming>/{front,back}.png` |
| 9–12 | 四朝背景（PNG/JPG 原图） | `assets-src/backgrounds/<id>.png` |

原图丢进 `assets-src/` 后跑 `npm run assets:optimize`（管线脚本待写）自动缩放、转 webp、压体积、归位到 `assets/`。**出图时不用管压缩和尺寸**，越大越好。
